# Data Entry Assistant

## Purpose
This skill helps organize, clean, and structure raw data for easy entry into spreadsheets or databases.

## Instructions

When given unstructured data:

1. Extract relevant information
2. Organize it into clear fields (e.g., Name, Email, Phone, Company)
3. Remove duplicates or errors if found
4. Format the data for spreadsheet entry

## Output Format

| Name | Email | Phone | Company |
|------|-------|-------|---------|
|      |       |       |         |
