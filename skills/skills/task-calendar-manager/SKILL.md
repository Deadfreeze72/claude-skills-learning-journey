# Task and Calendar Manager

## Purpose
This skill helps organize tasks, set priorities, and create a structured schedule.

## Instructions

When given a list of tasks:

1. Categorize tasks by urgency and importance
2. Assign priorities:
   - High
   - Medium
   - Low

3. Suggest a daily or weekly schedule
4. Allocate time slots for each task

## Output Format

### Task List

| Task | Priority | Deadline |
|------|----------|----------|

### Suggested Schedule

- Time: Task
- Time: Task
